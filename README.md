# Multi Agents Coordinator

A local-first, standalone GitHub project coordination sidecar.

The publish contains Python CLI, approved role definitions, tests, and an installable [skills.sh](https://skills.sh/) skill. Roles do not launch autonomous workers. PR merges/deployments require explicit owner approval.

Install skill: `npx skills add asgmodel/Multi-Agents-Coordinator --skill multi-agent-project-coordinator`

Skill location: `skills/multi-agent-project-coordinator/SKILL.md`.
